# Часть 1. Класс динамического массива

Ветка: `part1-dynamic-array`

Класс `DynamicArray` — динамический массив значений типа `int`. Память выделяется через `new[]`, освобождается в деструкторе. Все значения в массиве должны лежать в промежутке **−100…100** (включительно).

## Выполненные задания

### Задание 1. Базовый класс

- Поля класса: указатель на данные (`data_`) и размер массива (`size_`).
- `explicit DynamicArray(std::size_t size)` — конструктор с размером; элементы инициализируются нулями.
- `~DynamicArray()` — освобождает память.
- `void print() const` — выводит все значения в формате `[1, 2, 3]`.
- `bool set(int index, int value)` — проверяет индекс на выход за границы и значение на принадлежность промежутку −100…100. При нарушении любой проверки массив не меняется, возвращается `false`.
- `bool get(int index, int& value) const` — проверяет индекс на выход за границы, результат записывает в `value`; при выходе за границы возвращает `false`.
- `std::size_t size() const` — текущий размер массива.

### Задание 2. Конструктор копирования

- `DynamicArray(const DynamicArray& other)` — глубокое копирование: выделяется новая память, данные копируются. Изменение копии не затрагивает оригинал.

### Задание 3. Добавление в конец

- `bool push_back(int value)` — добавляет значение в конец массива с расширением размера на 1 (выделяется новый блок памяти, данные переносятся, старый блок освобождается). Значение проверяется на промежуток −100…100; при нарушении массив не меняется, возвращается `false`.

### Задание 4. Сложение и вычитание массивов

- `void add(const DynamicArray& other)` — `this[i] += other[i]`.
- `void sub(const DynamicArray& other)` — `this[i] -= other[i]`.
- Размер исходного массива **не изменяется**.
- Если размеры не совпадают, недостающие элементы считаются нулевыми: обрабатываются только первые `min(size, other.size)` элементов.
- Проверка диапазона −100…100 к результату `add`/`sub` не применяется: она относится к значениям, передаваемым в `set` и `push_back`.

## Демонстрация

`src/main.cpp` по очереди показывает:

1. создание массива, `print`, `set`, `get`, а также отклонение `set` с индексом вне границ и со значением вне диапазона;
2. конструктор копирования: изменение копии не меняет оригинал;
3. `push_back` с допустимым (`60`) и недопустимым (`101`) значением;
4. `add` и `sub` для массивов одинакового размера и `add` с более коротким массивом.
