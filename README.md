# Часть 3. Добавление шаблонов

Ветка: `part3-templates`

Класс динамического массива из частей 1–2 превращён в шаблон `DynamicArray<T>`: теперь он хранит элементы произвольного типа. Для целочисленных типов сохраняется ограничение значений **−100…100**, для числовых типов добавлено вычисление евклидова расстояния между массивами.

## Выполненные задания

### Задание 1. Шаблонный класс

- `template <typename T> class DynamicArray` — массив элементов типа `T`.
- Интерфейс прежний: конструктор с размером, конструктор копирования, `size()`, `print()`, `set()`, `get()`, `push_back()`, `add()`, `sub()`.
- Исключения из части 2 сохранены: `std::out_of_range` при выходе индекса за границы.
- Проверка значения выполняется в методе `checkValue()` через `if constexpr (std::is_integral_v<T>)`: для целочисленных `T` значение вне промежутка −100…100 вызывает `std::invalid_argument`. Для остальных типов (`std::string`, `double` и т. д.) проверка на этапе компиляции отсутствует.
- Проверка применяется в `set` и `push_back`. Для беззнаковых типов проверяется только верхняя граница.

### Задание 2. Оператор вывода `<<`

- `friend std::ostream& operator<<(std::ostream&, const DynamicArray&)` — выводит массив в формате `[a, b, c]`, поэтому `std::cout << arr` работает для любого `T`, у которого есть `operator<<`.
- Метод `print()` использует этот оператор и добавляет перевод строки.

### Задание 3. Расстояние между массивами

`double distance(const DynamicArray& other) const` — евклидова метрика:

```
dist = sqrt(Σ (a[i] − b[i])²)
```

| Условие | Результат |
|---------|-----------|
| `T` — числовой тип (`std::is_arithmetic_v<T>`) и размеры совпадают | расстояние (`double`) |
| `T` — нечисловой тип (например, `std::string`) | `std::bad_typeid` |
| `T` — числовой тип, размеры разные | `std::invalid_argument` |

Для нечисловых типов `std::bad_typeid` пишется независимо от размеров массивов.

## Демонстрация

`src/main.cpp` показывает работу с двумя типами.

**Числовой — `DynamicArray<int>`:**
- `set`, `push_back`, конструктор копирования, `add`, `sub`;
- отклонение значения 101 (`std::invalid_argument`);
- вывод через `<<`;
- `distance` для массивов `{0, 0}` и `{3, 4}` (результат `5`) и `std::invalid_argument` при разных размерах.

**Нечисловой — `DynamicArray<std::string>`:**
- `set`, `push_back`, конструктор копирования, вывод через `<<`;
- вызов `distance` приводит к `std::bad_typeid`.
